# Telegram Funstat Parser Bot

**Русский | [English](README_EN.md)**

Многофункциональный Telegram-бот для парсинга чатов и поиска пользователей по ID или username.

## Возможности

- Поиск пользователя по ID или username и просмотр истории его сообщений в чатах
- Парсинг участников и сообщений из Telegram-чатов
- Система кристаллов
- Реферальная система
- Мини-игра «Угадай число»
- Личная статистика пользователей
- Таблица лидеров
- Админ-панель для управления парсингом, импортом, банами и кристаллами

## Быстрый старт

### 1. Скачать проект

Открой терминал и выполни:

```bash
git clone https://github.com/ТВОЙ_USERNAME/ТВОЙ_РЕПОЗИТОРИЙ.git
cd ТВОЙ_РЕПОЗИТОРИЙ
```

### 2. Установить зависимости

Убедись, что у тебя установлен Python.

Затем выполни:

```bash
pip install -r requirements.txt
```

### 3. Настроить конфигурацию

Создай необходимые конфигурационные файлы:

```bash
cp .env.example .env
cp config.example.json config.json
```

После этого открой файл `.env` и укажи необходимые данные:

```env
BOT_TOKEN=токен_бота
API_ID=твой_api_id
API_HASH=твой_api_hash
```

Также проверь и при необходимости настрой `config.json`.

Не передавай другим людям `BOT_TOKEN`, `API_HASH` и другие секретные данные.

### 4. Авторизация в Telegram

Выполни:

```bash
python authorize.py
```

Следуй инструкциям в терминале.

На номер телефона, привязанный к Telegram, придёт код подтверждения. Введи его в терминал.

### 5. Запуск бота

После завершения настройки выполни:

```bash
python main.py
```

Если конфигурация настроена правильно, бот запустится.

## Решение проблем

Если проект не запускается, сначала проверь:

1. Установлен ли Python.
2. Установлены ли зависимости:

```bash
pip install -r requirements.txt
```

3. Правильно ли заполнен файл `.env`.
4. Правильно ли указаны `API_ID` и `API_HASH`.
5. Правильно ли указан `BOT_TOKEN`.
6. Что в терминале нет ошибок при запуске.

Если появляется ошибка, при обращении за помощью приложи полный текст ошибки из терминала.
